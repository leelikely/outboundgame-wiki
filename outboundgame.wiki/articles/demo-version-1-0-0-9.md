# Demo Version 1.0.0.9

**Release Date:** March 13, 2026

## Change Notes

- We made some adjustments to the default volume of the game, as it was low compared to other titles. Also reduced the idle motor volume.
- Added sliders for Narration and Thunder volume settings
- Fix on some environmental sounds being muted, like the campfire sound when it is on
- Add one missing icon for a campfire on the map
