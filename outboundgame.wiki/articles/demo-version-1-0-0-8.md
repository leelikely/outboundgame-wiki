# Demo Version 1.0.0.8

**Release Date:** February 27, 2026

## Change Notes

- Fixed that roof pieces can be built right away without rotating. Also remember the last build rotation for a better build experience
- Moved the check on a Version Mismatch in multiplayer to before the loading screen
- Properly remove the "Track a landmark" objective when nothing can be tracked anymore
- Increased stability of Unstuck mechanism
- Some more improvements were done for networking stability
